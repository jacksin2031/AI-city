# 本机照片预览与隐私边界

Owner：A / Main。参与页面允许用户在明确勾选本机临时预览同意后，选择本机照片或使用浏览器提供的拍照入口。照片通过浏览器 `blob:` URL 临时预览，不写入应用的本地存储、数据库、服务器或外部模型，不使用照片生成角色。照片预览同意与后续样本角色的公开同意分开；该本机勾选不构成服务端留存的授权记录。

预览只接受大小不超过 8 MiB 的 JPEG、PNG、WebP，并检查文件签名；图片解码失败或解码后尺寸超过 2000 万像素时清除。用户可主动删除预览、撤回同意或离开当前步骤；页面隐藏、退出及组件卸载时撤销应用持有的 URL。浏览器及操作系统控制底层文件与内存，应用不能保证物理擦除，亦不会删除用户相册或系统相机可能保存的原图。

照片入口不接受任意 SVG，不把文件名或内容发送至接口。后端仍严格拒绝照片字段，客户端存储安全规则仍拒绝读写。合成图片测试验证同意、失败、清除及未发出 POST；私有存储规则需在模拟器中验证。移动设备的系统相机、文件选择器、操作系统留存行为及生产环境尚未验收。未来如需发送照片、生成角色或公开照片衍生内容，必须另行设计明确的用途、授权、私有存储、留存、删除和服务端校验；现有本机同意与样本公开同意均不能替代该流程。
