# 双人责任与交接

| 范围 | 主责 | 另方提供 |
| --- | --- | --- |
| 手机、管理、任务、队列、权限、同步、文本服务 | A | B 的素材接口和状态需求 |
| 照片外观抽取、模板、四方向、动画、Phaser 和行为 | B | A 的受控输入、存储、公开事件和文本结果 |
| Contracts、版本、跨端验收 | 每项变更指定一名 owner | 另一方审查兼容性和证据 |

A 负责“任务可靠完成”，B 负责“结果正确展示”。当前账号映射未完成；`jacksin2031` 仅为已确认仓库负责人，不能虚构第二位 Code Owner。

交接至少包含：Issue、输入/输出样例、文件范围、状态语义、错误和回退、验证结果与未验证项。外部接口变更先更新 contract，再调整双方实现。一个工作目录只允许一个 AI 执行写入；两人各自 clone，或使用各自 worktree。
