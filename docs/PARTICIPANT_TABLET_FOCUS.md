# 参与者请求平板聚焦（本地样例）

现有持久访客页面在公开成功后可请求聚焦；服务端从有效访客会话读取本人的已公开角色，再检查当前公开名单。配对展示端在 LIVE 模式读取短期请求，并在自己的最新名单中再次检查角色后复用现有镜头选择。输入不能指定角色 ID。未公开、撤回、无会话或未配对时拒绝或不展示。

请求只在单个服务进程内保存 10 秒，采用最新请求覆盖，不保证并发请求全部展示、跨进程传递、重启恢复或平板已执行的确认。手机提示仅表示请求已发送。服务默认配置不启用持久访客；不代表已经发布到现有云服务。

本分支基于 main 的既有参与页面，与 `codex/participant-interface` 工作树中的新版日语界面尚未合并；照片、自定义示例图形、AI 问卷及全屏角色卡仍需与真实的预览、公开同意、会话恢复和撤回流程整合。不得仅用客户端勾选代替服务端验证。实际手机和平板、目标网络、部署版本及长时间运行均未验收。
