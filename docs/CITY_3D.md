# 3D 御茶ノ水街景

平板与 `/city` 的街景来自用户提供的 Blender 场景 `School.blend`（场景 `Ochanomizu`，约 790 × 730 m，42 万面），由 three.js 以固定的西北方向正交视角渲染。2.5D 插画街景已停用。

## 重新导出

在本机 Blender（5.x，无需网络、不调用付费服务）执行：

```bash
blender -b School.blend -S Ochanomizu --python scripts/blender/export-ochanomizu.py -- apps/web/public/city3d
```

约 15 秒，输出到 `apps/web/public/city3d/`：

| 文件 | 内容 |
| --- | --- |
| `city.glb` | 静态场景（约 30 MB，未压缩）；建筑的 `base_z`、`name_ja` 作为 glTF extras |
| `vehicles.glb` | JR 中央线·总武线、丸ノ内线与汽车模型；当前文件不含动画 |
| `traffic.json` | 本地导出的道路及轨道折线、车辆初始位置、推定停车线和车站位置 |
| `materials.json` | Blender 程序化材质的颜色与图案尺寸，由 `packages/city/src/materials.ts` 在着色器中重建 |
| `nav.bin` | 1 m 步行网格：每格类型（人行道、空地、草地、支路、主路、不可走）与高度（cm） |
| `places.json` | 网格范围、车辆循环长度，以及从店面雨棚找出的 215 处店铺位置与朝向 |

隐藏集合（导航网格、地下、路径、控制器）不导出。地下铁隧道等不可见物体不进入网页。

## 运行时

- 坐标：x 向东、y 向南（Blender 的 −Y）、高度向上，单位米。
- `mergeCity` 按材质合并约 1000 个网格为约百个 draw call；建筑按名称得到稳定的随机色调。
- 当前导出的 `LM_waterras_tower_7` 含有偏离建筑数百米的顶点；渲染时仅剔除此模型边长超过 250 米的异常三角面，并保留原始 GLB。受损局部尚未从 Blender 原始模型重建；重新导出后需复核此处理。
- 居民为面向镜头的 SVG 插画精灵，被建筑遮住时以半透明身影显示；放大展示中的居民总在最前。
- 镜头放近时，视野中心附近的建筑逐渐变透明，移开或拉远后恢复；透明度按建筑范围计算，不影响道路等其他场景。
- 可点击尼古拉堂、汤岛圣堂大成殿、明治大学 Liberty Tower、御茶之水 Sola City 与 JR 御茶之水站；选中时建筑闪白并显示日文介绍、实景照片及资料来源。照片来自 Wikimedia Commons，作者、许可、拍摄年份与原文件链接在界面中标示；御茶之水站照片为 2007 年旧站舍。减少动态效果时以静态高亮代替闪烁。名单仅覆盖已核对模型与资料的地标。
- 秋季光线按显示设备本地时间自动变化：06:00–09:59 早上、10:00–15:59 下午、16:00–18:59 黄昏，其余为夜间；切换前 30 分钟逐步过渡。为风格化视觉效果，不代表实时天气或精确日出日落。
- 已连接的平板页面让街景铺满可用视口，保留全屏按钮、住民选择和样例说明。不同屏幕比例以居中裁切保持画面比例；浏览器系统全屏仍需用户点击按钮且受设备支持情况限制。
- 居民沿步行网格 A* 走到地标（JR 两个出口、两座桥、ソラシティ、ニコライ堂、湯島聖堂、明治大学等）或店铺门前。
- 嵌入贴图通过 `<img>` 加载以符合 CSP 的 `connect-src 'self'`。
- 交通使用本地模拟时钟：41 辆汽车使用既有模型、分布在 16 条道路，信号每 40 秒循环；汽车在匹配的黄灯及红灯前停车，并在同一路径保持间距。列车在推定的御茶ノ水站台停车至少 15 秒，于下一模拟分钟发车。显示的交通、信号周期和列车班次均非实时或实际时刻表。
- 可选的角色对话仅供虚构预设与示例住民使用：角色靠近时向服务端请求日语短对话，成功播放的文本标记 AI。默认关闭，未配置时不调用模型；真人参加者不会被发送到模型。暂停动画时不启动对话。
- `traffic.json` 从 Blender 管线的 `vehicles.json`、`signals.json` 生成，信号根据道路距离、朝向、高度匹配；月台中心由场景几何估算。行人接近匹配方向及高度的行人信号时，在红灯和闪烁绿灯前等待，稳定绿灯时出发；已进入路口的行人继续通行。灯光与行人共用模拟时钟。重新生成：`python scripts/build-traffic.py <vehicles.json> <signals.json> apps/web/public/city3d/traffic.json`。重新导出模型后应同时重新生成并验证交通数据。
- 丸ノ内线列车使用轨道模型 `Rail_Metro_Marunouchi` 的垂直偏移，使两方向列车与可见轨道保持同一高度；其他路线不使用此偏移。
- `/city` 的「イラストの見本」提供 12 名虚构居民作演示；新增角色共用占位画风，不写入参与者数据或服务端。
- 管理页面可选择最多六名虚构预设住民，与参加者一起显示；样例名称和资料卡明确标识。选择仅保存在设备连接服务的进程内，重启后清空；展示上限 20 人，参加者优先。

## 已知限制

- `city.glb` 未压缩；量化或 meshopt 压缩需额外工具，尚未加入。
- 目标平板的帧率、内存与长时间运行尚未实测。
- 居民之间没有避让；汽车不避让行人。行人仍可走未设置信号的道路，寻路不会强制经过斑马线；行人信号的位置和识别范围、汽车信号匹配及站位均为推定值，不包含完整道路规则或实际列车调度。路线末端会重新进入，模拟时钟不会跨设备同步。
