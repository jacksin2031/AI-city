# 手机管理与平板联动

用户要求：管理在手机；手机与平板无论同一 Wi-Fi 或不同网络都能联动。Owner：A / Main。分支基于 PR #14，保留原有本地参与、公开确认和撤回。

方案：同源 HTTPS 中央服务，手机管理登录后发一次性平板配对码，平板凭只读 HttpOnly 会话读取控制状态与公开快照。手机切换见本/参与者/休止、暂停动作、撤回居民、解除平板配对；平板没有管理操作。控制带 revision 防旧请求覆盖；轮询不重叠、4 秒限时、断线清除旧数据，重连重新对账。

本地 loopback 可从 /setup 领取临时管理钥匙，生产默认仍关闭。跨网运行必须显式配置精确 HTTPS origin 和至少 32 字符管理密钥；远端禁用 bootstrap，Secure cookie，严格 Host/Origin、JSON 大小与角色检查、配对码短期单次、失败限流。不得通过 URL、日志、前端环境变量或二维码传管理员密钥/会话。

本轮沿用虚构样例、单 Node 进程内存；重启撤销会话并清空状态。网络无关协议不等于已部署或实际跨网验收；远端需一个 HTTPS 实例，不支持多实例/持久化。不得自动部署公开服务、扩大 IAM、调用付费模型、收真实照片或声称生产身份系统已完成。部署具体产物准备后再按项目规则确认。

按顺序交付：严格 DTO/负向测试 → 配对和角色服务/测试 → HTTP 安全边界 → 手机/平板 UI → 真实独立浏览器 context、375px/1024px、撤回/权限/断线/重连/CSP → 独立安全审查 → commit/stacked PR 与启动/部署指南。实际手机/平板及不同网络需在可访问 HTTPS 地址上独立验收。
