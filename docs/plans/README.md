# 计划书

两份均为简体中文，以日本公众为主要服务对象，要求所有 UI 使用日语，并明确项目用于向路人展示 AI 的强大能力。

- A 手机参与流程与云端服务：[可检索 Markdown](part-a.md) / [Word](AI_City_Plan_Part_A_手机流程与云端.docx)
- B 角色生成与城市展示：[可检索 Markdown](part-b.md) / [Word](AI_City_Plan_Part_B_角色与城市展示.docx)

Markdown 从本次 Word 正文和表格提取，供 AI 按相关章节读取，不必反复解析二进制文件。两种格式当前内容一致；计划更新应在同一个 PR 同步，并核对格式版本，发现冲突须明确指出，不能静默覆盖。

计划中的性能、辨认度和工期为目标，不是已完成的测试结果。当前 repo 实际状态以源码、测试、Issues 和 `docs/SETUP_STATUS.md` 为准。
