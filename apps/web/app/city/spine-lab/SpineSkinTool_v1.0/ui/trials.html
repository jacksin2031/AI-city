部位の画像生成
毎回、選択した元のキャラクター写真を Image 1 として必須送信し、新しい髪型・服装・色はこの写真から作ります。Image 2 は中性キャンバス/アンカーガイドで、旧素材の輪郭は含みません。Image 3 は固定再利用する頭部・耳です。Harri の胴体・腕・脚で部品の構造を確認し、Davide/Spineboy の線・色面・簡単な陰影を参照します。髪型・服装・色は元写真から決めます。胴体に肩・袖を描かず、肩は腕の上端に含めます。腕と脚は太さのある筒形、手は指のない半円形です。パンツの脚色は胴体裾の色帯と揃えます。後髪は後頭部を覆う一続きの簡潔な形にし、正面と同じ頭部スケールで輪郭を比較します。組立順は正面・側面で脚→胴体/スカート→腕→頭部、背面で脚→腕→胴体/スカート→頭部です。耳は背面以外で元の部品を表示し、髪の後ろに置きます。袖は袖色の濃い線、肌と半円の手は濃い肌色の線を残します。肩・袖は腕だけに含め、胴体の上端は連続した凸の丸い形にします。見えない服装は自由に選び、選択した配色を全パーツで共有します。髪の生成には旧キャラクターの髪画像を入力しません。以前の生成部位・候補・プレビューはモデル入力に含めません。やり直しは元写真を維持して説明文を変更します。GPT Image は ChatGPT ログイン済みの公式 Codex CLI 内蔵生成を使います。OpenAI API Key は不要です。購読枠の残量は確認できません。初期設定は事前確認のみです。
