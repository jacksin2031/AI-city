# 文件分类与发布说明

| 类别 | 位置 | 处理 |
|---|---|---|
| 程序与契约 | src、ui、templates、schemas/prompts、runtime版本/锁文件/配置样例 | 公开，ui是通用工具页面代码，不含本人素材 |
| 当前文档 | 根说明/AGENTS/DISTRIBUTION和白名单docs | 公开，014/standard-ear-001优先，旧章节不是新指令 |
| 开发测试 | tests、scripts/check_*及capture_*、fixtures/synthetic | 公开源码；所需原参考已按清单同仓提供。合成fixture为固定SHA、非真人；原参考贴图另按专门清单收录 |
| 本人素材图/任务/新Spine | runtime/work、data、output | 本机持久资料，不公开、不删除；新人物raw/export/bundle不能混进模板 |
| 测试网页数据/证据 | work的批次/审核/会话、logs的截图/进程记录 | 本地，不公开；通用页面源码保留，新装无旧案例 |
| API与本地配置 | runtime/secrets/*、config/local.toml、.env* | 私密不打包；旧providers.json可能仍有API key，保留本机不打印 |
| 本人订阅凭证 | 系统凭证库或CODEX_HOME/auth.json（默认用户目录.codex） | 工具外，不读/复制/迁移，每个操作者自行登录 |
| 订阅上下文/原始返回 | work角色会话/模型事件、Codex用户目录sessions/generated_images | 私人，不共享；会话ID不是登录凭证，但同样不上传 |
| 原Spine参考库/固定母版 | references/spine | 随仓库与ZIP发布，工具直接读取。原工程与同级images/export保留；原许可证随包，贴图仅参考/非商用，221文件逐SHA锁定 |
| 旧私用参考库 | runtime/vendor-untracked/reference-library；相邻library | 仅兼容旧安装，不作为新环境前置；不上传这些目录中的其他素材 |
| 环境与缓存 | runtime/python/.venv、js/node_modules、cache/tmp/bin、js/runtime | 不公开，按锁文件重建，不搬个人环境 |
| 开发历史 | docs/evidence、plans、changes本机历史 | 本地保留，公开包排除；仓库另有干净初始导入记录，当前限制看RELEASE_STATUS |
| 源码ZIP/私人备份 | runtime/output/M08 | 默认不公开；仅白名单源码ZIP可显式复制到Git发布目录，PRIVATE_BACKUP绝不上传 |

DISTRIBUTION是允许发布规则，未列入内容不因“像配置”而自动带入。白名单目录只允许代码/文本后缀，普通目录中的额外PNG/照片/Spine/ZIP不入包；reference目录仅允许ASSET_MANIFEST列出的原工程/固定母版/贴图及许可证，逐SHA验证，合成PNG也单独固定哈希。扫描高可信API key/GitHub token/JWT/私钥样式，错误不回显值；仍须核对Git暂存路径与包内清单。

本人原始照片、生成数据和凭据全部留在本机；获准随包发布的原参考副本按清单收录。清洁交付通过白名单副本实现，不对本人工作区破坏性清理。原参考按原包许可证随文件发布：图片禁止商用，“仅参考”不扩大许可；本人账号权限仍由操作者满足，不承诺订阅无限使用。
