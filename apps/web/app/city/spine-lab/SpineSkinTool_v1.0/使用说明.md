# Spine Skin Tool 使用说明

本目录即工具根目录，可独立复制，不需要AI City。AI先读本文件、AGENTS、文件分类与发布说明、RELEASE_STATUS，再读当前贴图/审核规范。以下命令在工具根目录的PowerShell执行，含空格路径加引号。

## 1. 新环境准备（一次性）

安装runtime/versions.toml指定的Python3.12.10、uv0.9.18、Node22.17.1、pnpm11.9.0及官方原生Codex CLI。Windows需Microsoft Edge供动作图证；Spine Editor、4090不是基本流程必需。账号/CLI必须支持内置ImageGen，不支持时停止，不使用API替代。

```powershell
python -B scripts/bootstrap.py --install --online
runtime/python/.venv/Scripts/python.exe -B scripts/doctor.py --json
```

--online明确允许下载锁定依赖，不调用模型、不升级全局软件。指定Python缺失时先安装该版本；bootstrap不偷偷安装全局Python。缓存完整时省略--online离线安装。每台机器自行重建环境，不复制个人.venv/node_modules。

## 2. 已包含的原始参考库（无需导入）

工具默认直接读取`references/spine`，与GitHub和ZIP中的路径一致。原始素材和运行母版分别为：

```text
references/spine/
  ASSET_MANIFEST.json
  REFERENCE_ONLY.md
  Chibi-Stickers-4.3/extracted/
    chibi-stickers-pro.spine      # 原始Spine工程，只作参考
    license.txt                  # 必须随素材保留
    images/                      # 原工程对应分件贴图，保留相对目录
    export/                      # 原包JSON/atlas/PNG/skel导出
  ai-city-spineboy-skin-v13/spine-export/
    ai-city-original-template.json
    ai-city-original-template.atlas
    （实际装配读取的对应PNG）
```

原包199文件保持原字节与相对路径，另包含实际使用的固定运行母版；全套221参考文件逐SHA锁定。Harri参考部件构造，Davide/Spineboy参考大致画风，EriKari参考裙摆，真人照片控制新角色形象。不能复制原参考人物发型/服装或裁切其轮廓当新素材。

原生.spine供参考/Editor查看，程序实际读取同一参考库内的JSON/atlas/PNG；不必安装Spine Editor才能制作。原许可证允许工程作为衍生基础，贴图随许可证可再分发但禁止商用；“仅参考”不授予商用权。详情见references/spine/REFERENCE_ONLY.md。旧runtime/vendor-untracked私用导入和相邻library仅作兼容，不再要求对方提供这些目录。

## 3. 本人登录与一次启动

环境准备完成后，双击根目录`启动工具.cmd`。等价命令：

```powershell
runtime/python/.venv/Scripts/python.exe -B scripts/launch.py --subscription --open-browser
```

启动器检查仓库参考清单、复用本人ChatGPT CLI登录；未登录时调用官方`codex login`由本人完成。随后自动初始化缺失配置并启用设计/生图/审核本地开关，打开制作页；网页会沿用已启用订阅选项，不必手工编辑JSON或再找参考素材。点击制作前0模型调用。新配置各通道累计预留上限示例为24，已有上限与全部旧预留保持不变；额度不足时明确停止，不删记录或假装免费。

这是操作者本人显式启动的订阅制作入口，点击制作会上传选定照片并消耗本人订阅可用量。工具不复制他人凭证、不读取auth.json/系统凭证库、不继承网页账号，不查询剩余额度，不回退OpenAI Images API。账号/CLI须支持内置ImageGen，不可用时如实停止。官方登录方式见[官方文档](https://learn.chatgpt.com/docs/auth?surface=cli)。

仅检查素材和登录、不改配置或调用模型：

```powershell
runtime/python/.venv/Scripts/python.exe -B scripts/launch.py --check-only
```

高级用户仍可用configure_subscription.py初始化缺少的配置，或显式--enable --max-calls调整本地上限；这是可选维护入口，正常启动无需执行。照片/API配置/订阅会话仍留在本机忽略目录。

## 4. 启动、制作与查看

```powershell
runtime/python/.venv/Scripts/python.exe -B scripts/start_trials.py --port 8783
```

终端保持运行，Ctrl+C退出，只监听127.0.0.1。端口占用可另选端口，不终止不认识的服务。访问http://127.0.0.1:8783/characters。

1. 导入本人的原照片、填角色说明，照片按SHA保存在本机work，不进入Git。
2. 建立新角色任务，按需启用设计/生图/审核开关；订阅启动入口已准备本地配置与页面默认选项，仍可手动关闭或只保存计划。建议暂停在设计阶段确认；下装拍不到时AI可按整体设计。
3. 推进制作：头发/衣身/裤腿使用原照及对应原参考；标准腕本地配色。无耳头发先适配，再按原照逐侧事实补标准小耳。一人物一会话，每件初次+最多3修，不跨会话重置。
4. 查看正背面、走跑/挥手/表情与审核图；网页保留全部候选、失败原因、每件尝试与耗时，标准腕/耳标明非AI。模型PASS或246帧不等于最终美术批准。
5. 下载选中候选运行包：Spine Runtime JSON/atlas/PNG/守卫脚本，不是Spine Editor原生.spine工程，不能改后缀冒充。

主要页面：/characters制作、/trials单件、/reviews审核、/repairs返修、/acceptance本地验收。/blind-trials、/hair-trials是通用比较页，需本机任务/批次ID；新装不含开发者旧照片/候选，旧URL不可直接复用。UI日语。

CLI共用scripts/pipeline.py：先import-photo --input "照片路径"；把返回photo文件名写入被忽略的任务JSON，再create --input runtime/work/任务.json、advance --id <flow-ID>、report --id <flow-ID>。完整字段见docs/CHARACTER_PIPELINE.md，不另写装配流程。

## 5. 中断、保留和维护

限流、超时、输出审核和结果未知分开记录。先看任务/错误/已返回结果，不删预留、不复制会话、不盲目重发；未知不能算没调用。旧候选保留比较，代码/规范变动使旧审核过期时重新核验，不能自动追认为通过。

照片与任务在runtime/work/data，人物与运行包在work/output，图证在logs，旧API配置在secrets；Codex本人凭证在系统凭证库/用户目录，角色上下文在work。备份恢复见docs/OPS.md，PRIVATE_BACKUP不可上传GitHub，工具也不备份密钥。整理采用白名单副本，不清空本人数据。

## 6. 给AI的复用指令

> 以本目录为根，读使用说明、AGENTS、RELEASE_STATUS和QUALITY/TEXTURE当前014节。确认锁定环境、本人ChatGPT CLI登录、仓库references/spine清单；使用订阅启动入口准备本地配置，不读/复制凭证，不重置预留。用户授权真实调用后用pipeline_service完成原照到候选，不另建提示词、模型层或装配层。每人物一会话，每件最多3修，标准腕/小耳记非AI。保留失败/未知，实际检查正背/动作，不把技术通过当美术批准。缺项明确报告。

## 7. 白名单打包

```powershell
runtime/python/.venv/Scripts/python.exe -B scripts/package_release.py --report runtime/output/M08/release-audit.json
runtime/python/.venv/Scripts/python.exe -B scripts/package_release.py --output runtime/output/M08/未存在的源码包名称.zip
```

规则取DISTRIBUTION.json，包内RELEASE-MANIFEST逐文件记录SHA与类别；只含源码/规范/样例/开发测试。原参考的.spine/skel/JSON/atlas/PNG仅按references/spine/ASSET_MANIFEST逐SHA收录并随原许可证发布；另有一张非真人合成fixture。本人照片/生成角色/凭据/依赖/旧历史仍不入包。高可信凭证样式检测失败则拒绝。不直接压缩整个目录、不执行git add .或强制添加忽略数据；GitHub只提交发布清单、公开发布记录和经核验源码ZIP。
