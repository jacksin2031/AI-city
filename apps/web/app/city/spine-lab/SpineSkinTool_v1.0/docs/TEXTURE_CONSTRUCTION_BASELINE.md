# Q 版角色贴图构造基准

## 当前014：单角色会话、部件作用域与独立贴合审核

每个角色绑定自己的持续Codex会话、原照片SHA和设计书；固定会话ID续接，禁止--last或跨角色历史。模型只负责这一人物，完成/有限失败后结束本轮会话并保留证据。外层执行模型显式请求gpt-6-luna/low；图像工具内部模型版本未暴露，不虚构具体GPT Image型号。CLI耗时不等于纯生图耗时。

衣身与腿的生图输入仅原照+对应Harri构造+Davide/Spineboy画风，共3图。腿写裤管布料与鞋；不附固定头/耳，不混入露肤、手臂、发型或面部叙述。标准腕继续代码配色与袖长处理，AI调用0；不改变原alpha结构和两类勾线。空白/不透明/坏图/结构错层仍拒绝。

前发左右连接处保留1～3%余量，当前测量取各侧1%头宽；下颌正常显露不算覆盖失败。原固定头模的侧颊采样截止78%头高，排除过去80～90%下颌被误作必须盖发的区域；这一分区是实验规则而非生产尺寸。发鬓底部单独按装配后与邻近头模轮廓是否自然贴合审核：历史第三例候补2轻微突出可接受，候补3细长尖鬓过长为反例，不要求发片底边与头模最低点水平齐平或围住下巴。前后整体高仍记录并保持近似，禁止横向拉伸。

只有明确定位为发鬓末端PROPORTION时，允许局部修改同一份冻结发片+头模组合参考，保持已合适的顶部、刘海、脸窗、宽度、配色与位置；每次仍带原照和原画风参考，不把上次编辑结果再作为下次目标。PNG画布以整体等比注册到原基底，非等比变化拒绝；不裁切原Spine轮廓，不用蒙版补救。其他重新设计仍从原照片开始。

耳模式先记录原照片左/右的VISIBLE、HAIR_OCCLUDED或UNCLEAR及原因，再由规则决定：任一侧可见或不确定均为PARTIAL_BOTH，只有两侧都明确被头发遮住才可HIDDEN。看不清耳形、照片转头导致远侧不可见，都不能直接选择隐藏。审核必须独立核对原照，不能仅信任模式字段。当前默认standard-ear-001：复用原Spineboy简化耳形，按固定头高约12%等比缩小，在已冻结耳根位置补上前后同高的小耳；耳形无需按真人定制，AI调用0，不重新生成头发或人物。原耳槽始终隐藏，不恢复原大耳。新增耳片内侧根部在侧发后、外侧部分在侧发前，形成夹在头发里的效果；只安排新耳片遮挡，绝不裁切/蒙版/拉伸或重采样原头发。前后原始发片和整人8件原稿SHA不变。两只耳分别至少40%可辨，目标约40～60%；后视自然多露允许，但不能为了可见性放大成大耳或挪动头发。必须有真实标准耳来源/工件和正常图的逐耳证据，模型PASS或合计像素不能代替。旧AI补耳流程仅按历史工件回放。

每角色每件最多初次+3次重生，服务拦截也计数，跨初次/修复/补耳共用持久计数，不通过换会话重置。已知拦截只能以新的正常部件说明重试；未知结果先收取已有结果，不能盲目重发。所有尝试、PNG、原因、会话归属、耗时和SHA留存。阶段辅助PASS不是整人/生产批准。

## 历史013：先头发、后补耳、共同高度坐标（由014修订）

本节取代下文历史012耳根先定位的执行顺序。头发从原照片+原参考全新制作，第一阶段严格不画耳朵/皮肤/头模；前后均正投影。先以原固定头模检查头顶/刘海/弯曲侧脸框与自然比例，只等比缩放和平移，不使用耳朵来决定头发尺寸或上下位置。前后画风只看同一2D插画Q版大类和彼此一致，不比较阴影/发束细节。

在同一head-local Spine坐标中记录前后“头模并集头发”的top、bottom、total height、差值；不能按两张PNG画布大小/留白/耳像素百分比定位。当前高度差8%为可审查实验容差，仍需整体自然，非最终生产尺寸；前后高度无法同时自然吻合时应重画对应整张无耳头发，不拉伸单轴。

无耳头发先通过几何与有效订阅视觉的hair_fit/hair_consistency阶段审查，才冻结基底、位置和哈希，进入耳部生成。补耳是明确有限例外：可参考同一份已确认头发+原头模拼装图，前耳通过有效ear_visibility审查后，背耳还可参考同一份已确认前耳。不能链式修改上次结果，不能把这种例外用到头发反复重画。

AI仅输出两个隔离的透明小耳片，按原头模肤色/深肉色线和本角色头发画风绘制。代码仅分离这些新生成耳片、整体等比缩放，按左右耳根共同head-local坐标定位，再合成进原前/后发PNG，头发和头模不重画、不按耳再定位。此处不是裁切原Spine头发或用头模轮廓蒙版。前后耳根高度共用同一数值，可因头发自然遮挡而只见部分；必须记录实际可见面积，遮挡未知不能伪称看到耳朵。原耳附件每个方向/表情仍隐藏，骨骼/曲线/原头五官不动。

输出保留无耳候选、前耳候选、前后耳候选及其材料/参考/审核/派生哈希与四项耗时。前耳未确认不制作背耳，头发未确认不补耳；未知、服务拦截或无效审核不得算完成。阶段通过不等于整人成品或生产授权。本轮每张照片输出一套新版角色候选，沿用此前每件初次后最多3次返修上限，不把“一版”误当成禁止纠错。未知或缺乏有效定向反馈时停止待审，不强行用满次数。


状态：`reference_hair_8part_v2` 实验性制作契约，生成提示词版本由 `runtime/versions.toml` 的 `models.image_prompt_revision` 管理。当前统一契约按用户 2026-11-02 粗粒度画风、正背投影及余量要求改写，替代旧“衣身含肩线/后肩”“正面手臂藏在衣服后面”“挥手在脸前”的规则。历史证据与旧候选不改写；新三角色独立保存，流程版本由 runtime/versions.toml 的 workflow.revision 管理。

像素尺寸、16.5 cm、锚点和比例均未批准为生产设定。现行流程已在三位角色的聊天制作中试验并同步到工具；结果可浏览，仍须用户确认，见 CHAT_VALIDATED_FLOW.md。

## 输入来源与画风

- 八张基本贴图为前后各一张 HAIR、BODY、ARM、LEG；默认 HAIR/BODY/LEG 从原照片生成，ARM 采用用户批准的 Harri 标准结构配色（AI 调用0），来源必须区分。可选裙装增加独立 SKIRT_FRONT/BACK；BLANK 由程序产生。头模、五官、表情及特效沿用原 Spine。原耳朵在所有方向、表情和动作混合中隐藏；当前按HIDDEN或PARTIAL_BOTH制作：先无耳发片，再按需添加标准小耳并合成（非AI、约头高12%）；不恢复原大耳槽。
- 每次从同一张原始真人照片重新生成，只改文字提示词。照片决定可见发型等设计线索。照片不完整时可自由搭配完整衣装并记录为设计选择；明确可辨的下装或用户指定才锁定相应部分。照片未显示的后发结构仍按可见发型合理推断；不把任何自由设计写成照片事实。之前的生成素材、候选、拼装图不得传回模型。
- Harri 原 body/arm/leg 是部件拆分和简化结构的首要参考：衣身没有肩部，肩帽在手臂顶端；手臂和腿是有厚度的简约长筒，手是半圆封口。Davide/Spineboy 只提供大致2D插画Q版画风，阴影/笔触/细节画法不必复刻。原角色的发型、图案、身份、衣装和颜色不得照搬，也不按其 alpha 裁切新角色。
- 照片中的写实骨骼、手指、肌肉需按Q版结构简化；不画细长肢体、解剖细节、明显写实大类或破坏可读性的随机坏点。允许原素材少量受控笔触，不把脏污颗粒当作手绘风格。衣纹用清晰、少量线条表达，不凭空新增 Harri 标志。描边与各材质同色系：袖/肩帽使用更深袖色，裸露腕与半圆手使用深肉色；不能以平涂抹掉原肉色边线，不能全身统一黑边。标准配色须保留原alpha与勾线结构，再按对应材质染线。
- 五张固定输入：Image 1 原始照片；Image 2 无角色轮廓的中性画布/中心锚点；Image 3 固定原头模（头发请求不展示原大耳）；Image 4 Harri 对应原部件（裙层改用 EriKari 原裙）；Image 5 Davide 与 Spineboy 对应原部件组成的风格板。头发任务的 Image 4/5 都用原 body，不发送原角色头发或生成的正发。五图数量保留以兼容现有 provider 接口。
- 每张输出为一个孤立 RGBA 部件、真实透明、无标注或背景。生成分辨率、输出画布、像素主体范围、Spine 几何和锚点独立记录；不把实验参考尺寸写成最终比例。

### 裤装、裙装与层级

裤装：BODY 下沿保留连成一体的弧形/碗形腰臀三角区色带，实际裤腿归 LEG。三角区与裤腿以冻结主色为指导，允许相近色调和阴影差异；不加独立漂浮裤子，也不让上衣颜色误延伸成裤腿。照片未显示下装时，先记录统一的推断配色并复用于全部相关部件。

裙装：独立可选裙层，参考原 EriKari 裙摆宽度和实际 trot 腿部扫掠范围，逐帧核对遮挡，不并入 BODY/LEG；明确裤装或用户指定裤装时不擅改裙装；下装不可见时可在共享设计书中自由选择裙装。

正面动作的目标绘制顺序（从后到前）：**腿 → 衣身／裙子 → 双臂（含肩帽/袖子/半圆手）→ 头部组（头模、耳朵、五官、表情与对应头发）**。侧面沿用正面顺序。背面从后到前：**腿 → 双臂 → 衣身／裙子 → 头部组**，衣身/裙层必须盖住腕。包括挥手与 trot 极值，所有方向的手臂都不得穿到头部前。背面后发完整遮住头模、衣身无肩，逐方向实际验收。提示词中的顺序只是装配要求，PNG 无法设置 Spine draw order；现行导出在运行时应用此顺序；旧实验包保持历史行为。

## GPT Image 提示词结构与工具入口

`generation.py:PART_PROMPTS` 定义八个基本部件及两个可选裙部件的独立内容与禁画项，`build_part_prompt` 统一附加以下英文短字段。`trials.py:trial_request` 导出的每个部件也调用同一函数，不再维护另一套不完整生成提示词。ComfyUI/GPT Image/Grok 共用规则。

```text
Use case: stylized-concept
Asset type: one isolated RGBA texture layer for a rigged 2D chibi character
Input images: 1 original photo; 2 neutral canvas/anchor; 3 fixed head for fit, skin and linework;
              4 original Harri component construction/style;
              5 original Davide/Spineboy component style sheet
Primary request: <one part and its allowed structure, using PART_PROMPTS>
Style/medium: original-skin simple 2D chibi, broad flat colors, clear economical
              contours/garment lines, sparse shadows, broad hair clumps
Assembly contract: front/side LEGS < TORSO/SKIRT < ARMS < HEAD_GROUP;
                   rear LEGS < ARMS < TORSO/SKIRT < HEAD_GROUP;
                   original ears hidden in ALL states; small new ears inside hair;
                   rear hair fully covers rear head; no baked adjacent parts
Contours: darker shade of each material; warm dark skin-tone on arm/hand,
          sleeve-tone on shoulder/sleeve; retain original outline structure
Constraints: true transparency; fixed head/expressions; integrated small ears; experimental
             canvas/anchors; no old alpha clipping; separate optional skirt
Avoid: <part-specific forbidden content>; realistic anatomy, fingers,
       skinny limbs, scalp-like or patchwork hair, grain and extra parts
Design notes: <photo-visible design, shared outfit/pants palette, marked inferences>
```

正背头发的轮廓比较是**生成后的审核**。每次后发仍只接收原照片和原始参考，不把生成的正发当输入。生成前可将已锁定的发长/颜色/体积写成共同文字说明；生成后比较同一头模坐标中的轮廓，不对有脸开口的正发与全封闭后发机械要求 alpha IoU 一致。

## 人工验收

3. 将正背发片按相同头部尺寸和锚点对齐，保存原始 alpha 与主要不透明主体范围；比较发顶高度、两侧宽度、整体体积、发色和线稿。轻微差异需能由真人发型解释；明显变宽/变高/像换发型则拒收。阈值待校准，不能杜撰自动评分或简单拉伸硬凑一致。
4. 全身与头部/肩部近景检查，源 Harri/Davide/Spineboy 与候选用相同镜头核对风格和比例；不能只看 PNG 画布大小。固定头模/五官/表情哈希保持不变，原耳附件不改像素但所有状态隐藏。
5. Runtime 检查 idle/trot 的前后左右：起始、极值、回中；再检查表情和 wave。正面/侧面采样帧必须满足腿<衣身/裙子<手臂<头部组，背面为腿<手臂<衣身/裙子<头部组，尤其跑动抬臂/挥手不得穿脸。背面检查衣肩外翻、后发完整覆盖和头颈关系。原工程未提供独立 walk/run/talk，不能声称这些新动作已验收。
6. 1×/2×/4× 导出保持同一几何并保存图证；检查腿根缝隙、阴影色差、方向切换、网格变形；裙装额外核验实际腿部扫掠。尺寸或几何问题另立实验，不能用旧角色轮廓遮罩裁成一致。

不以旧图的画布、轮廓IoU、包围框像素偏移拒收新发型。允许宽高/透明脸部开口/外轮廓改变，100～150px只是示例，不是新上限。前发包住固定头模的头顶、太阳穴和侧脸框，中央五官留白；头发与头模组合自然圆润，不强制圆形。仅允许整张等比缩放，严禁把失败素材横向拉伸、挤压或套蒙版；等比放大使高度鼓胀时，按所需覆盖宽度从原照片重新综合生成整个发型。后发只要求与前发的画风处理一致、覆盖自然，不额外要求零渐变或固定一个阴影。前后图不相互回传生成，仅共用冻结文字设计。每件初次生成后最多3次返修，从同一原照片/原参考重新生成，保留全部结果与未通过原因。

## 正背视角、余量与自动返修

FRONT/REAR均须严格正投影，禁止半侧脸/三分之四/斜头透视，即便原照片斜拍；侧分发/偏侧发髻可以不对称，不能连头骨与脸窗都转向。生成引导允许1～3%连接余量，旧版004拟合使用+3%头模覆盖测量目标；当前005改为下节耳根先定位再检查侧框与头顶，保持实际头模/PNG像素不变，只整体等比定位。透明脸窗须有正确重叠，不能横向拉伸、切片补边或盲放大发窗。

画风只检查大类与前后头发一致。阴影、发丝数量、高光、笔触差异不作拒收原因。服装类型/大致主色正确即可。订阅视觉模型按这些固定规则输出具体缺陷和部位；返修沿用同一模板，自动加入绑定该审核/部位/证据哈希的具体观察文本，不能让观察覆盖原规则。无需聊天手写每次提示词；不是让模型自由改掉基础规范。

## 历史012耳根先定位的制作契约（已由013替代）

Image 3现在是原固定头模及原工程测得的两个耳根连接目标（青色十字），不是发型、裁切轮廓或要印入成品的标记。前发连同小耳从原真人照片全新绘制：耳根对应该目标高度和间距，不落在下颌/脸颊下缘；用原头比例设计头顶到耳根的距离，避免“耳朵虽对齐但头发肿高”。耳朵部分可藏入头发，但两侧连接处须有可测量的肤色，不画整脸或头皮。

装配先按两耳根定整体等比缩放和平移，不再由覆盖面积优先任意压低头发；随后检查原头模弯曲侧边是否有连续露框、头顶和眉眼留白、前后自然量感。不满足时重画整张前发，不单独拉耳朵、不横向拉伸、不继续上下移动掩盖冲突。后发是连续不透明后脑发帽，内部前脸开口数量必须为零；无需生成前面耳朵或复制前面刘海。

每轮仍只接收原照片和原参考。原头模、五官、表情、原骨骼和动画不改，原耳全部隐藏。标准腕仍为本地Harri结构配色。每件初次后最多3次返修，全部尝试和失败原因保留。
