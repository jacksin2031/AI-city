# 受控素材修订与历史纹路试验

当前规则见 TEXTURE_CONSTRUCTION_BASELINE.md、QUALITY.md 和 TASK-M07-HAIR-EARS.md。用户2026-11-02明确取消旧轮廓像素锁：旧图的画布、alpha IoU与bbox偏移只作诊断，不作头发拒收门禁，100～150px只是示例。头发按固定头模侧脸覆盖、自然圆润比例和画风判断；只允许整体等比缩放，禁止横向拉伸/蒙版补救，鼓胀时整体重新生成。

原耳所有状态隐藏，新小耳与前发一起生成并部分夹在头发里，匹配原头模肤色/线稿。后发只需与前发画风一致，不额外强制零渐变/固定阴影数量。头模、五官、骨骼及动作保持原样。

工具的自动 HAIR_REFRESH 流程每次从同一原照片/原参考生成，不回传失败图或拼装图。初次前后发各1件，每件至多3次返修；未知结果、额度中断和输出拦截停止，不以新会话绕过上限；每次真实PNG和原因保留可浏览。非头发原稿明确标复用，不声称整套重新生成。

texture_edit 仍可记录用户明确允许的固定基础编辑例外：每次同一固定基础而非上次结果，最多3次跨会话累计。当前检查不再用旧轮廓变化拒绝，只检查真实RGBA/有效内容并要求装配和视觉复核。这个旧聊天编辑入口不冒充新的原照片自动重制流程。
