# 人工质量审核规则（未校准）

## 当前014：单角色会话、部件作用域与独立贴合审核

每个角色绑定自己的持续Codex会话、原照片SHA和设计书；固定会话ID续接，禁止--last或跨角色历史。模型只负责这一人物，完成/有限失败后结束本轮会话并保留证据。外层执行模型显式请求gpt-6-luna/low；图像工具内部模型版本未暴露，不虚构具体GPT Image型号。CLI耗时不等于纯生图耗时。

衣身与腿的生图输入仅原照+对应Harri构造+Davide/Spineboy画风，共3图。腿写裤管布料与鞋；不附固定头/耳，不混入露肤、手臂、发型或面部叙述。标准腕继续代码配色与袖长处理，AI调用0；不改变原alpha结构和两类勾线。空白/不透明/坏图/结构错层仍拒绝。

前发左右连接处保留1～3%余量，当前测量取各侧1%头宽；下颌正常显露不算覆盖失败。原固定头模的侧颊采样截止78%头高，排除过去80～90%下颌被误作必须盖发的区域；这一分区是实验规则而非生产尺寸。发鬓底部单独按装配后与邻近头模轮廓是否自然贴合审核：历史第三例候补2轻微突出可接受，候补3细长尖鬓过长为反例，不要求发片底边与头模最低点水平齐平或围住下巴。前后整体高仍记录并保持近似，禁止横向拉伸。

只有明确定位为发鬓末端PROPORTION时，允许局部修改同一份冻结发片+头模组合参考，保持已合适的顶部、刘海、脸窗、宽度、配色与位置；每次仍带原照和原画风参考，不把上次编辑结果再作为下次目标。PNG画布以整体等比注册到原基底，非等比变化拒绝；不裁切原Spine轮廓，不用蒙版补救。其他重新设计仍从原照片开始。

耳模式先记录原照片左/右的VISIBLE、HAIR_OCCLUDED或UNCLEAR及原因，再由规则决定：任一侧可见或不确定均为PARTIAL_BOTH，只有两侧都明确被头发遮住才可HIDDEN。看不清耳形、照片转头导致远侧不可见，都不能直接选择隐藏。审核必须独立核对原照，不能仅信任模式字段。当前默认standard-ear-001：复用原Spineboy简化耳形，按固定头高约12%等比缩小，在已冻结耳根位置补上前后同高的小耳；耳形无需按真人定制，AI调用0，不重新生成头发或人物。原耳槽始终隐藏，不恢复原大耳。新增耳片内侧根部在侧发后、外侧部分在侧发前，形成夹在头发里的效果；只安排新耳片遮挡，绝不裁切/蒙版/拉伸或重采样原头发。前后原始发片和整人8件原稿SHA不变。两只耳分别至少40%可辨，目标约40～60%；后视自然多露允许，但不能为了可见性放大成大耳或挪动头发。必须有真实标准耳来源/工件和正常图的逐耳证据，模型PASS或合计像素不能代替。旧AI补耳流程仅按历史工件回放。

每角色每件最多初次+3次重生，服务拦截也计数，跨初次/修复/补耳共用持久计数，不通过换会话重置。已知拦截只能以新的正常部件说明重试；未知结果先收取已有结果，不能盲目重发。所有尝试、PNG、原因、会话归属、耗时和SHA留存。阶段辅助PASS不是整人/生产批准。

## 历史013：先头发、后补耳、共同高度坐标（由014修订）

本节取代下文历史012耳根先定位的执行顺序。头发从原照片+原参考全新制作，第一阶段严格不画耳朵/皮肤/头模；前后均正投影。先以原固定头模检查头顶/刘海/弯曲侧脸框与自然比例，只等比缩放和平移，不使用耳朵来决定头发尺寸或上下位置。前后画风只看同一2D插画Q版大类和彼此一致，不比较阴影/发束细节。

在同一head-local Spine坐标中记录前后“头模并集头发”的top、bottom、total height、差值；不能按两张PNG画布大小/留白/耳像素百分比定位。当前高度差8%为可审查实验容差，仍需整体自然，非最终生产尺寸；前后高度无法同时自然吻合时应重画对应整张无耳头发，不拉伸单轴。

无耳头发先通过几何与有效订阅视觉的hair_fit/hair_consistency阶段审查，才冻结基底、位置和哈希，进入耳部生成。补耳是明确有限例外：可参考同一份已确认头发+原头模拼装图，前耳通过有效ear_visibility审查后，背耳还可参考同一份已确认前耳。不能链式修改上次结果，不能把这种例外用到头发反复重画。

AI仅输出两个隔离的透明小耳片，按原头模肤色/深肉色线和本角色头发画风绘制。代码仅分离这些新生成耳片、整体等比缩放，按左右耳根共同head-local坐标定位，再合成进原前/后发PNG，头发和头模不重画、不按耳再定位。此处不是裁切原Spine头发或用头模轮廓蒙版。前后耳根高度共用同一数值，可因头发自然遮挡而只见部分；必须记录实际可见面积，遮挡未知不能伪称看到耳朵。原耳附件每个方向/表情仍隐藏，骨骼/曲线/原头五官不动。

输出保留无耳候选、前耳候选、前后耳候选及其材料/参考/审核/派生哈希与四项耗时。前耳未确认不制作背耳，头发未确认不补耳；未知、服务拦截或无效审核不得算完成。阶段通过不等于整人成品或生产授权。本轮每张照片输出一套新版角色候选，沿用此前每件初次后最多3次返修上限，不把“一版”误当成禁止纠错。未知或缺乏有效定向反馈时停止待审，不强行用满次数。


质量政策 quality-mvp-002 为历史冻结实验政策，自动视觉 PASS 关闭。现行用户制作规范直接作为审核判据；M05-05校准验证判别器是否可靠，不要求重新批准已确定的画风/部件条款。M05已实现检查、证据采集和订阅视觉辅助；完整语义校准尚未完成。本清单定义当前实验候选的人工验收，不批准生产像素尺寸、16.5 cm 物理比例或自动视觉 PASS。模板风格、目标显示尺寸和误报阈值仍待黄金样例/缺陷样例校准。

## 判定记录

每张部件图、每个要求视角和动作分别记录 `PASS`、`FAIL`、`UNKNOWN`（历史文档的 `NOT_CHECKED` 对应未确认），附缺陷描述、PNG SHA-256、导出画布与 alpha 范围、trial/profile 参数、实际预览截图和 Spine 动作名。状态含义如下：

- `PASS`：所有适用的硬性和语义检查均通过，并有图片/播放证据。
- `FAIL`：任一硬性约束不符，或出现明显不可接受的错位、裂缝、缺件、覆盖、穿插、风格漂移。
- `UNKNOWN`：没有实际检查的视角、动作、分辨率或证据，或结论不确定。不得当成通过；整套聚合为 `REQUIRES_REVIEW`。

整套候选仅当所有必查项均为 `PASS` 才能标为“人工候选通过”；任何 `FAIL` 或 `NOT_CHECKED` 都将整套结论置为未通过/待检查。PNG 可读、Runtime 成功加载、无浏览器错误、动画能播放只证明技术路径可运行，不是素材质量结论。人工候选通过也不等于生产批准。

## 生成来源与重试记录

- 每次生图/重试都必须附带同一张原始角色照片作为主要设计来源；改变由更新文字提示词、禁画项或几何说明实现。
- 之前生成的部件图、拼装预览和候选贴图只用于人工对比，禁止作为下一轮编辑图像输入。目标附件、固定头模及 Harri/Davide/Spineboy 原始部件可以按提示词角色作为几何、复用和画风参考。
- 记录原始照片与固定参考图哈希、提示词版本/全文、模型原始输出、输出哈希和人工结论。任何一张头发参考图缺失或来源不明时，标记 `NOT_CHECKED`，不以旧候选代替原图继续生成。

## 所有部件的硬性拒收项

1. 内容违反部件契约：额外画了不属于该层的头模、脸、袖子、裤腿或其他独立部件；固定复用资产被重绘/替换；服装结构错误。
2. Alpha/画布异常：白底假透明、空白层、孤立杂点/杂块、缺失主体、越界或意外透明孔；导出画布、profile、mesh/UV 版本不匹配。
3. 几何和拼接错误：目标部位明显偏移、缩放失衡或比例不符；与相邻部位之间出现背景缝、重叠双线、露馅边缘、明显裁切或穿插。
4. 播放时出现静态图看不到的闪烁、滑动、网格拉裂、方向错误、前后层级错乱或附件漏显。
5. 只拒绝明显跨绘画大类（如2D插画Q版中混入写实照片/真实3D/像素风），或前后头发画风明显不一致；阴影、发束数量、笔触和高光逻辑不要求复刻原Spine，其他部件细节差异不拦截。

## 头发专项硬性检查

### 前发

- 在固定原头模上叠图核验发顶、左右太阳穴、侧脸框与发际线；头顶或太阳穴出现不合理裸露带、头发小到像假发片、位置偏离头模，即 `FAIL`。
- 发片主体必须视觉连贯。贯穿发束/头顶的透明裂口、露底孔、孤立透明洞、遮罩切出的尖缝和中线断口均为 `FAIL`。只在真人角色参考明确有自然分缝时允许窄发缝，且不得透出背景或形成断裂观感。
- 不遮眼眉与表情活动范围；原耳所有状态隐藏，小耳画在前发PNG中且部分夹在头发里，肤色/线条与固定头模协调。不含整个头模、脸、五官、表情或脖子。
- 记录新图 alpha bbox、画布、锚点和对固定头模的实际覆盖。默认不套用旧发片 alpha 遮罩；禁止用旧轮廓裁切或横向拉伸来适配。模板网格仍会影响 Runtime 变形，若变形令新发型接近旧角色轮廓或产生裂缝，直接 `FAIL` 并记录为几何限制。

### 后发

- 在固定头模与当前独立 `back-hair` region 上确认后脑、头顶和左右轮廓连续覆盖，不出现不合理肤色/背景条带；发梢应停在后颈上方，不能连画脖子、身体或衣服。网格只用于动作变形检查，不是后发造型的来源。
- 不含脸、五官、头皮、脖子或衣服；后发自然遮耳；发片没有中线断口、孔洞、孤岛或裁切尖缝。
- 后发为完整连续的简洁 Q 版发块，背面无需露头模；头皮式纹理、拼接发片、只有明显变成写实绘画大类才FAIL；普通细发束/明暗层次不独立拒收。
- 与正发在同一固定头模尺寸、相同锚点下比较发顶高度、两侧宽度、整体体积、发色与线稿；保存轮廓对照证据。正发有脸开口、后发全覆盖，不用两图 alpha IoU 强行判定；差异须有发型依据，明显失配即 FAIL。比较仅用于审核，生成后发不得输入生成的正发。

## 衣身与四肢专项硬性检查

- 正背 BODY 均为独立无肩衣身面；肩帽、袖子与全部肩部像素只属于 ARM。上沿必须最高点在正中的单一凸弧、领口只作内部线条；任一领口凹口/双肩峰、肩角外翻、颈后耸起、重复袖帽、肩部烘焙进 BODY 即 FAIL。
- 手臂是有厚度的简约长筒，手为半圆封口；分离手指/拇指、掌纹、细腕或细长写实前臂即 FAIL。腿为简约长筒，不刻画写实膝盖/肌肉/脚趾；与 Harri 原部件相同比例视图检查。袖/肩帽边线须为深袖色，裸露皮肤与半圆手边线须为深肉色；轮廓平涂消失或肤色边线误染袖色即FAIL。
- BODY 下沿连续碗形三角区与 LEG 裤装大致主色协调，允许相近色调差异或独立漂浮裤子。衣服类型和大致色调正确即可，纹样/阴影/还原度不作精细拦截。可见的随机坏点破坏素材时另行检查。
- 正面所有动作目标层级：从后到前 LEG_L/LEG_R < BODY/SKIRT < ARM_L/ARM_R < HEAD_GROUP。整个手臂含手必须在头模/耳朵/五官/表情与对应头发之下，trot 极值和 wave 均须检查，不能沿用旧手在脸前的判定。侧面同正面；背面必须 LEG < ARM < BODY/SKIRT < HEAD_GROUP，衣身/裙盖腕。

## Spine Runtime 必查范围

- 固定同一相机缩放，并排检查源基准和候选的全身视图及头部近景。
- 检查 `movement/idle-front/back/left/right` 与 `movement/trot-front/back/left/right`；每个相关方向至少检查动作起始、极值与回中帧。前发重点检查 front/side，后发重点检查 back/side。新流程原耳附件在全部方向/表情/wave/切换中均隐藏，耳朵画在前发PNG中，尺寸小且部分夹在头发里；肤色/勾线协调固定头模。不能按旧原耳非空要求误报缺耳。旧包按其保存政策回放。
- 检查可用表情和 `emotes/wave` 的遮挡。不得声称源工程没有的 walk、run、talk 已验证。
- 1×、2×、4× 导出均检查全身图与头部近景；不允许通过修改骨骼、mesh、UV 或非等比变形来掩盖贴图错误。
- 有裙层时检查所有 trot 采样帧的裙摆/腿部遮挡与穿插。

## 自动检查的边界

当前自动能力包括设计/照片/包哈希、原稿与导出alpha/空白/不透明背景/离群、共享处理重现及画布、标准腕配色/材质勾线RGBA、固定头模/表情/骨骼（原耳全部隐藏）/原atlas页完整性、实际Runtime四方向动作/表情/转向及1/2/4图集的层级/耳/活跃头发存在。孤立mask还记录头顶/后脑覆盖、腿根和去耳前后的像素差，但实验覆盖/裤色/杂点阈值只产生UNKNOWN，不能仅靠数值批准裂口/比例/风格/自然遮挡或裙摆穿插等语义。视觉模型可提供缺陷提示，但在正负样例、盲测和阈值校准之前只能标注为辅助结论，不能产生自动 `PASS`，也不能覆盖人工 `FAIL`。未知或未检查永远不是 PASS。

要启用自动视觉 PASS，还需积累人工通过/失败黄金样例、各缺陷类型的负例、目标分辨率截图、误报/漏报测量和跨角色盲测记录，在现行规范的明确正负例和独立留出测试中验证后单独版本化质量政策；不把重新批准既定规则当作运行测试的前置条件。对于证据不足或模型误判，继续待审。

## 三例试验新增审核点

- 不能以 alpha>0 包围框代替有效主体：先查看低透明杂点是否导致部件被缩小、腿根悬空；保留原图、实验清理阈值与删除 alpha 比例。禁止用原附件 alpha 将不透明模型输出伪装为分层。
- 盘发/侧拍照片必须转为合适的正面覆盖，不能保留侧向窄脸开口；两侧头框和眉眼均实际叠图检查。后发不传生成前发作参考。
- 复用裙子 weighted mesh 时检查对应原骨骼已在新皮肤启用，避免塌成尖形；在真实 trot 帧检查展开范围和腿遮挡。
- 标准腕作为用户批准的来源类别，记录原模板哈希、配色、袖长、alpha 保持、袖线/肉色线两类及 AI调用0。模型审核拒绝不是生图成功；不得静默复用旧生成图。
- 当前三个案例仅为本轮人工抽查和真实 Runtime 证据，不推定所有照片一键稳定，亦不等于生产倍率/真机验收。

## 当前头发验收修订

前发覆盖头顶/太阳穴及侧脸框，五官开口可读；头发+头模自然圆润，不是强制圆形。旧图轮廓像素差、IoU、画布或边界变化均不作为拒收门禁；100～150px为允许变化示例。允许整体等比放大，禁止横向拉伸/挤压失败图。若适宽后头高鼓胀，需要整体重新生成。后发画风只与前发一致，不单独强制零渐变/固定阴影数量；不因少量受控明暗而自动重画。所有语义判断需实际装配图证，未知不冒称通过。

## 历史012耳根定位与二阶段验收（已由013替代）

小耳存在、原耳隐藏不等于耳位正确。前发必须以左右实际耳根对齐固定头模的耳部连接目标，再做整体等比缩放与平移；目标由原工程耳网格的头局部连接高度投影到原头模边界，不复制原大耳轮廓。原头/耳图和骨骼不修改。

对齐后独立检查头顶、眉眼留白、两侧脸颊边框及整体头型。侧脸测量沿真实弯曲边界，不能再用矩形覆盖平均值掩盖连续露边。耳位对齐而头发过高/过宽、头顶不覆盖或脸框露出时，从原照片与原参考重新设计整张前发；禁止改耳位来补洞、非等比缩放或旧轮廓蒙版。
