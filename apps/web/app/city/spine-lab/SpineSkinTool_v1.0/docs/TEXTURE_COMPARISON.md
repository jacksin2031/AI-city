# 纹路编辑的只读比较

此页用于查看曾被实验守卫拒绝的真实输出，供用户对比后决定是否修订要求。它不改变规范、阈值、历史判定、三次上限或quality_approved，不自动采用任何素材，也不发送生成/审核请求。

入口：本机工作台 `/texture-compare?session=<texture会话ID>`。前发、后发各显示原图与最多3次实际结果，点击缩略图或选择编号即可组成右侧角色。左侧保持编辑前；两侧共用相机、方向、动作时间和缩放，可播放待机/trot并叠加挥手等原有表情。原图叠加与差分使用PNG自然像素尺寸，CSS缩略图尺寸不参与计算。IoU和边界变化标记为旧实验指标，不能代替头部覆盖、比例或画风审核。

## 装配方式

复用当前唯一 `character.region` 和官方Spine Canvas Runtime。只根据冻结的基础原图计算一次前/后发矩形与锚点；所有编辑保持该坐标映射，不对编辑图重新找包围盒或重新拟合。不裁切、重采样、修复透明度，也不套原角色发型轮廓。骨骼、IK、头耳表情、衣装、层级、动作不改。完整PNG直接成为独立图集页，原PNG字节与来源SHA可核验。比较视图使用固定相机，避免自动取景掩盖几何变化。

私有展示副本位于对应会话的 `comparisons/`，显式 `comparison_only=true`、`quality_approved=false`、`production_approved=false`。它没有正常character设计/raw导出结构，不进入候选采用和审批路径。源bundle、原始素材、事件记录与预算不变；源文件及编辑结果变更会阻止继续读取。首次完整解码验证后，每次HTTP读取复核冻结字节，避免每个并发图集请求反复占用worker写锁而误报忙碌。

“编辑元的保存済み組立”链接另开原来实际保存的归一化bundle预览。比较用基准保留原始PNG完整画布，因此与过去去透明边距/清理极低alpha后的bundle存在边缘采样差异；不宣称逐像素完全一致。此差异不会在各编辑间分别重拟合，也不等于美术通过。

## 边界

仅loopback；Host检查沿用工作台。图片路由只接受前/后发与0～3编号，不暴露照片、prompt、context、文件路径或密钥。比较视图只允许manifest、Runtime脚本与明确列出的图集资源，下载与任何批准写操作被拒绝。源码与测试不包含私人PNG。

此功能仅完成六次历史输出的只读比较。没有完成自动艺术验收，不代表M07整体完成，也没有复跑编辑图的完整246帧审核。用户确认要调整哪些规则后，另行版本化修改正式规范与审核器。
